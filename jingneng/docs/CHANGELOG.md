# 定制修改清单

归档日2026-11-20，以运行源码及最近交付为准，不沿用早期“计价未接入”“附件阈值40%”的旧状态。

## 流程与反馈

- 草稿到报价、发送、合同和销售确认，阶段发生时间单独保存。
- 首次发送日期用于报价样本归属，中标/失标/待反馈与合同状态独立。
- 反馈日期、失标原因、备注、下次跟进日期和报价版本关联。
- 合同转订单继续保留状态、权限及业务校验。

## 图纸与选型

- 图纸与选型页签位于明细之前，取消顶部重复识图入口。
- 多文件上传、后台识图与方向缓存；滚轮缩放、中键平移、双击中键适应页面。
- 尺寸辅助最终采用手动框选。正视图宽/高、侧视图深度直接回填，不另设确认写入步骤。
- 无图纸报价直接选产品与录入参数，不走上传图纸入口。
- 机箱机柜/附件分类，柜型：JA、JC、JE、JK、JM、JP、JP WIDE、JQ、JS、JS WIDE、操作台。
- 材质、料厚、门型、喷塑和颜色独立配置，门型支持前后单/双开门及背板组合。
- 宽度表达式识别单柜/并柜，不增模式切换；每柜配置，订单数量按组。
- 附件汉字重叠率60%建议，支持人工添加/取消；单柜自动归属，并柜指定柜位/整组；实测附件尺寸不擅自猜定。

## 计价与内部明细

- 原报价服务真实规格与成本计算，保存当前计算快照，不自动创建原系统正式BJ报价/合同。
- 当前计算与历史已保存结果独立；历史缺项不编造补零。
- 材料单价按材质，固定镀锌板部件独立取价；规则和材料价格参数参与失效判断。
- 原软件分项折扣：可折部分打折，固定附件/运费不重复折扣；原生整行折扣为零避免二次打折。
- 旧材料缺价标记仅在完整版本化板件结果逐项核验后窄兼容；原响应及标记保留。
- 数量、规格、材料单价或系数变化后要求重算，客户输出阻止旧快照。
- 面价/成本明细、成本列分组、附加利润、列设置、批量系数和中文单位。
- 草稿名称人工编辑、规格独立展示，并柜可展开；报价信息首组冻结且适配列宽。

## 列表、分析与客户输出

- 数量标题改订单编号；去掉销售团队、有效期至等停用入口；承诺交货日期保留一个入口。
- 客户/销售人员筛选、状态及反馈结果、阶段时间、报价转化和销售业绩。
- 报价单保留原生透视，订单入口按单据汇总进度。
- 导入识别京能报价2表头，空白模板不预填客户、产品和正式编号。
- 对客八列与内部成本分开；保护人工名称和空/换行备注，长备注续页。
- 报价输出参考原报价2纸面；销售订单和形式发票保持原容器。
